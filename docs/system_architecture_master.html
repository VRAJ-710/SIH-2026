Cyclone Amphan: 8–23°N, 82–92°E

1. Ingestion Sources & Standardization CF-1.8 NetCDF & Parquet
Grid Reanalysis: Copernicus GLORYS12V1 NetCDF-4 (113.9 MB). Dimensions: time:13, depth:50 (0.494m to 5727.9m), lat:181, lon:121 (~8km resolution). Variables: temperature, salinity, current_u, current_v.
In-Situ Point Instruments: Ifremer Argo GDAC ERDDAP (15,689 rows, 21 floats, Core T/S + BGC Chl-a), INCOIS OMNI buoys (468 rows, BD08/BD11/BD14), BoBBLE Seaglider SG620 (1680 rows), ADCP current moorings (108 rows), CTD casts (56 rows), CSV text (16 rows).
Unified Melted Schema (8-col Parquet): lat, lon, depth, time, variable, value, instrument_id, instrument_type. Loaded via generic glob("points_*.parquet").
2. Dockerized Compute & Serving Tier Docker Compose Linking
Unidata THREDDS Server (TDS 5.8): Container sih_tds on port 8080. Serves ncWMS 1.3.0 GetMap/GetCapabilities in CRS:84 (fixed lon/lat axis order, zero inversion). Slices NetCDF along TIME and ELEVATION with palette mapping (psu-magma, viridis).
FastAPI Microservice (Python 3.12): Container sih_backend on port 8000. Serves /instruments, /instrument/{id}/profile, /volume, /variables, /plugins, /health (dual-mounted at /api/health).
In-Memory Stores: Thread-safe DataStore (Parquet dataframe + model xarray handle) and VolumeStore with threading lock. Benchmarked latency: 15–45ms.
3. Browser Presentation Tier (React 19 + TypeScript) Vite Dev:5173 / Nginx Prod
CesiumJS Globe Engine (v1.145): World Bathymetry, WebMapServiceImageryProvider with GeographicTilingScheme, in-situ CustomDataSource point billboards. Stage 10 Offline Resilience: 6s timeout interceptor auto-swaps to bundled NaturalEarthII tiles and EllipsoidTerrainProvider.
Three.js Subsurface Engine (v0.186): Direct GPU Volume Raymarching with Data3DTexture + Marching Cubes isosurface extraction. Land sentinel tolerance: <= -9998.5 sets transparency. Post-processing: EffectComposer + UnrealBloomPass.
Plotly & Interaction UI: Multi-axis depth profiling with collocated observed vs. model traces and MAE banner; GSAP colorbar controls drawer; 5-beat Cyclone Amphan guided tour.
